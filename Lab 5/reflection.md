# Lab 5 – Reflection

### 1. What did you learn from this lab?

I learned how static code analysis tools such as Pylint, Bandit and Flake8 help identify code-quality, security and formatting problems without executing the program.

### 2. Which tool was most useful and why?

Bandit helped identify security-related problems. Pylint helped improve code quality and readability, while Flake8 helped maintain consistent formatting.

### 3. What challenges did you face while fixing the issues?

One challenge was correcting exception handling and adding input validation without affecting the functionality of the parking permit management system.

### 4. How will you use static code analysis in future projects?

I will use static analysis tools regularly to identify issues early, improve readability, maintain coding standards and reduce security risks.
